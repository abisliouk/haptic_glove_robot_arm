# Interfacing Haptic Glove

## Project Overview
This project is part of the **EEL 5934 - Autonomous Robots** course at the University of Florida. Our goal is to interface a **haptic glove** with a robotic system, enabling remote manipulation of objects. The project involves integrating **ESP32 robotic arm kits** and an optional **VR environment** to enhance the user experience and control.

## Project Goals
### **Robotic Embodiment**
- Use a **haptic glove** (and optionally **VR**) to manipulate objects remotely.
- Achieve fundamental robotic interactions:
  - **Grab, pick, and place objects**
  - **Basic motion control**
- Bonus: Utilize **VR to control a ROS-based digital twin** of the robotic system.
